# 11-2: Analogの描画・登録・差分復元

作成日: 2026-09-28。状態: 完了（2026-09-29、[検証記録](11-2-validation.md)）。上位仕様は[作業11](plan.md)、依存は[11-1](plan-11-1.md)。

## 1. 到達点

Analogを3つ目の文字盤として選択し、黒背景、白い針、オレンジの秒円、日付、情報欄を表示する。
長押し・選択保存・復帰を既存経路へ接続し、差分更新で針の跡や重なりの欠けが残らない状態にする。

## 3. ライフサイクルとフレーム

beginはviewport・既存フォント・アイコンマスク等を準備する。endは資源と描画履歴だけを解放し、制御側の状態を維持する。
再初期化と失敗後のendを安全にし、既存HomeLayerの前文字盤／Digitalへの退避を使う。
初期実装で全画面キャッシュを作らない。任意キャッシュの失敗は直接描画へ退避し、毎フレーム再確保しない。

updateで共通制御へ入力し、planで同じスナップショットから配置・文字・変更キーを確定する。paintは確定済みデータだけを使い、RTCや保存へアクセスしない。
要素は時針・分針・秒円・中心円・日付・電池・情報0・情報1の8個を基本案とする。FramePlanの容量32と他レイヤーの要素数を確認する。
消えた要素も空矩形へ更新して旧領域を消す。秒OFFや時刻無効化も同じ経路を通す。

## 4. 描画とdamage

描画順は黒背景→日付・情報→時針→分針→中心円→秒円。
線は`drawWideLineClipped`を利用し、円も既存AA関数がdamageを尊重するか確認する。必要なら小さなクリップ対応円描画を追加する。
黒背景はRendererの基底復元を利用する方針とし、opaqueAreaは既定の空矩形でよい。

AA余白つき矩形と意味上の変更キーをFramePlanへ登録する。同じ矩形のまま回転する場合も変更を検出する。
damageと交差する要素は未変更でも描き直す。各描画でPaintContextへクリップし、解除後に領域外を書かない。
一覧背景は黒、自身は静止しenv.clipで被覆される。被覆から露出した帯の復元を確認する。

日付・情報は既存フォント、供給アイコン、幅制限・省略を使う。Analogではグレーと黒の合成でよいが、11-3で多色背景用の文字描画へ対応できる責務分割にする。
大きなVLWのスタック確保や、共有化のための巨大な常駐バッファを避ける。

## 5. 実装順序

1. ライフサイクルと契約を実装し、登録・ビルドへ接続する。
2. 固定データで針・秒円・日付を描き、画像基準の配置を確認する。
3. 情報欄、共通制御、期限、保存を接続する。
4. 変更判定と復元を実装し、基本の画素比較を追加する。
5. ホストテスト、通常版と描画検証版ビルドを確認する。

## 6. 検証と完了条件

- 設定の3番目に現れ、選択と秒設定を保存する。戻る・A+Bで表示される。
- 秒円だけの更新、10秒境界、日付更新、無効時刻、秒OFFで旧位置が消える。
- 針同士、針と日付・情報の交差が全面描画と一致し、damage外は不変。
- 情報増減、長い日本語、不正アイコン、電池条件変化を表示できる。
- 一覧の部分被覆と往復、文字盤切替、再初期化で古い要素が残らない。
- 任意キャッシュやフォントの代替経路でも表示が成立する。
- 丸だけが変わる秒に針を変更扱いにせず、不要な全面更新を発生させない。

結果は`11-2-validation.md`、ログ・画像は11-2名で保存する。
実機未接続なら画素比較・目視は未実施として11-4／11-5へ渡す。全回帰・性能はこの段階だけで完了扱いにしない。
