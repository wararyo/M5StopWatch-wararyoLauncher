# 11-4: 描画比較・操作・保存の統合回帰

作成日: 2026-09-28。状態: 計画（未実装）。上位仕様は[作業11](plan.md)。
依存は[11-2](plan-11-2.md)・[11-3](plan-11-3.md)。目視・性能受け入れは[11-5](plan-11-5.md)へ渡す。

## 1. 到達点

両文字盤の差分描画と全面描画が一致し、4文字盤の選択・操作・保存と既存画面が退行していないことを確認する。
ホストテストのPASSと実機画素比較のPASSを分け、未実施を完了扱いにしない。

## 2. 変更対象と比較方法

`tests/watchface_tests.cpp`・`ui_tests.cpp`・`runtime_tests.cpp`の責務に応じてケースを追加し、`tools/test_runtime.py`で実行する。
Gfxを含む描画は`src/host/RenderDiagnostics.cpp`の既存の全面／差分比較へ追加する。
偽ポートによる選択テストだけで実際のHomeLayer登録を確認済みとせず、登録本体は描画診断・実操作でも確認する。

前フレームから差分更新し、同じデータ・秒設定・情報・一覧進捗の全面描画と比較する。
基準側へ途中の長押し・保存が混入しないよう、両側の状態を揃える。
不一致時はケース名、時刻、バリアント、情報、clip、damage、最初の不一致座標と件数を記録する。必要な場合だけ比較画像を保存する。

## 3. 描画ケース

| 分類 | 必須ケース |
|---|---|
| 秒 | 両文字盤で00〜59、59→00、ON→OFF→ON |
| 針 | 水平・垂直・斜め、一致・反対・交差前後、同一境界矩形内の回転 |
| 時刻・日付 | 9→10日、月末→1日、23:59→翌日、無効→有効→無効、時刻の前進／後退 |
| 情報 | 0／1／2件、増減・並び変更、長いASCII・日本語・省略、不正アイコン |
| 電池 | 29／30／31%、充電開始／終了、不明と回復、電池＋情報2件 |
| 重なり | 針と日付／情報／別の針、背景境界と文字／アイコン／秒円 |
| 被覆 | 一覧進捗0・途中・1と往復、通知・統計の出現／消去 |
| Noonish | 背景のみ／丸のみ／両方の変更、境界AAの反復描画 |

直積で全組合せを増やさず、境界と経路を覆う代表ケースを選ぶ。秒円の全60位置は省略しない。
Noonishは背景も動く連続時刻と、固定背景で境界を跨ぐ丸の配置を分けて確認する。
damage外の不変、反復描画によるAAの濃化がないことも確認する。

## 4. 入力・期限・保存

- 4件＋戻るの移動・タップ／B決定・A+Bホーム、選択マーク、スクロール。
- Tap無操作、LongPress1回切替、解放時タップ抑止。
- ホーム限定長押し、ドラッグ取消、A/B同時成立、復帰タッチ消費の既存テストを維持。
- 秒OFFは10秒期限、ONは秒境界。完全被覆・他画面・消灯では文字盤期限を待たず、復帰で最新値。
- 表示対象情報のみ期限を持ち、時刻無効でも情報は更新。
- Analog秒ON・Noonish秒OFFと逆の状態を往復・再構築して独立復元。
- 選択保存失敗・バリアント保存失敗・未知版・未知ID・begin失敗を偽バックエンド等で検証。
- 未知IDテストのanalog等は、そのテストの候補集合で未登録か確認。本番追加を理由に無関係なテストを機械的に変更しない。

## 5. 実装・実行順序

1. モデルと偽ポートの境界ケースを追加し、ホスト全スイートを実行する。
2. 描画ケースを追加し、通常・描画検証・測定の3構成をビルドする。
3. 既存の書込保護・構成／パーティション／イメージ検査手順で診断版を準備する。
4. 実機比較をケース群に区切り実行し、失敗だけ詳細調査する。
5. Digital／Forest、設定・一覧・通知・ストップウォッチの主要既存ケースを確認する。

作業10で大量比較中にwatchdog警告が出たため、群の間で待機タスクへ実行機会を与える方法を現行コードに合わせて検討する。
watchdog無効化やタイムアウト延長で隠さない。継続する警告は画素比較と別に記録し、製品版での再現有無を11-5へ渡す。

## 6. 完了条件と証跡

ホストテスト・対象画素比較・既存の主要回帰がPASSすること。
実機未接続や故障注入未実施は明記し、模擬失敗と実機故障を区別する。
`11-4-validation.md`へケース数・結果・未実施・イメージ識別と構成を記録する。
ログは日時・11-4・構成・ケース群が分かる名前で直接保存し、終了コードと要約だけ取得する。
