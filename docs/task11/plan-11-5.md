# 11-5: 実機の見た目・性能・保存復元と完了判定

作成日: 2026-09-28。状態: 計画（未実装）。上位仕様は[作業11](plan.md)、依存は[11-4](plan-11-4.md)。

## 1. 到達点

最終構成で両文字盤が使えることを、実機の見た目・操作・保存復元・性能・メモリで確認する。
検証後は通常版へ戻し、完了項目と残課題を文書へ反映する。

## 2. 準備と比較条件

- ブランチ・リビジョン・未コミット差分、基板、電源、輝度、消灯、CPU／DFS、USB・統計表示の有無を記録。
- `m5stopwatch`、`m5stopwatch-render-check`、`m5stopwatch-measure`の最終イメージを識別可能にする。
- 現行ツールで書込保護・構成・パーティション・4MiB容量・イメージを検査。ホスト以外の領域を消去しない。
- 現在のDigital／Forestも同条件で測り、過去ログだけとの比較で劣化を断定しない。
- 一時変更する輝度・消灯時間と終了時の復元値を先に記録。

## 3. 目視と操作

両文字盤で情報なし／あり×秒OFF／ONの4状態を画像取得し、基準画像と実機を確認する。

- 針の太さ・端・中心、秒円の径と軌道、日付と情報の位置・読みやすさ。
- Analogのグレーとオレンジ、Noonishの4色・境界AA・10秒刻みの動き。
- Noonishの秒円が境界を跨いでも背景色が分かり、明るさが蓄積しない。白混合率50%から調整する場合は値と理由を記録。
- 針と文字の重なり自体は許容仕様。移動後の残像や欠けは不具合として扱う。
- 長押し、無操作タップ、上スワイプ、A/B、A+B、4文字盤＋戻る。
- 消灯中もストップウォッチが継続し、復帰で最新時刻・情報を表示。復帰タッチで秒設定が変わらない。
- 日付・時刻設定後に針と背景が更新。時刻無効等を診断で代替した場合は実操作と区別。

## 4. 保存と資源寿命

Analog秒ON／Noonish秒OFFと逆の状態を保存し、選択往復・再起動後の独立復元を確認する。
選択ID、輝度・消灯設定、Digital／Forestのバリアントも保持されることを確認する。
全文字盤を一定回数（初期案20周）切り替え、前後の内部RAM／PSRAM空き、最大連続領域、スタック余裕を記録する。
単一の空きメモリ差だけでリークとせず、反復後の減少が続くか確認する。
キャッシュ無効化・偽保存失敗は11-4を参照し、実ヒープ枯渇・実NVS故障を注入したとは扱わない。

## 5. 性能と任意の電流比較

| 測定区間 | 評価対象 |
|---|---|
| 秒OFF・情報なし | 10秒境界の針、Noonish背景 |
| 秒ON・情報なし | 丸だけの更新と10秒境界を分離 |
| 情報あり | ラベルと時計更新の同時発生 |
| 一覧往復・連続操作 | フレーム間隔、応答、背景更新との競合 |
| 消灯・復帰 | 最新状態への復帰、計測継続 |

既存診断に沿って描画・転送時間、フレーム間隔、damage面積／転送量、最悪ケースを記録する。
Noonishの背景更新を10秒全体の平均へ埋めず、そのフレームを個別評価する。
作業10の定常33.3ms以内未達を引き継ぎ、30fps超の操作指標と全フレームの期限保証を分ける。
通常操作で目立つ停止やwatchdogが出る場合は未完了として原因を調べる。描画・合成を修正したら関連する11-4画素比較を再実行する。
damageは1矩形へ統合されるため、複数領域の登録だけを改善策としない。

外部電流は環境が利用できる場合に実施する。電源電圧・輝度・USB／シリアル・統計表示を揃え、複数の10秒周期を含む区間（初期案60秒以上）を観察する。
表示色が異なるので電流差を描画負荷だけの差としない。USB電流を電池の持続時間と混同しない。
実測できなければ未実施と記録し、電池持ちの改善や同等性は主張しない。

## 6. 実行順序と完了条件

1. 最終ビルド・ホスト検証・イメージ検査と11-4の証跡を確認。
2. 描画検証版で最終画像と必要な比較を取得。同一イメージで完了した比較は理由なく反復しない。
3. 測定版で性能・メモリ・操作を確認。
4. 通常版へ戻し、イメージ一致・起動・再起動復元・消灯復帰を確認。
5. 任意の外部電流測定、一時設定の復元、シリアル取得の終了。
6. 文書へ結果を反映し、残課題を明示。

成果物は`11-5-validation.md`、各段階をまとめる`validation.md`、画像・ログ、更新した`docs/plan.md`と関連設計文書。
機能・画素一致・実機目視／操作・保存復元・容量と資源寿命の確認を完了条件とする。
性能値・既存未達・任意測定の有無を記録し、必須の未実施が残ればチェックを未完了に保つ。
大量ログは日時・11-5・構成・区間を識別できるファイルへ直接保存し、終了コードを保持する。要約と必要範囲だけ取得する。
