# M5StopWatch wararyoLauncher

M5StopWatch-MultiFirm の軽量ホストを目指すランチャーです。現在は、設計判断に必要な描画性能と待機電力を実機で測るための試作段階です。

## 現在の試作範囲

- M5GFX のみで描画するデジタル時計
- 時計を上へスワイプすると現れるアプリ一覧
- `A`: 次へ、`B`: 決定、`A+B` 0.6秒保持: 時計へ戻る
- 30秒無操作でパネルをOFF。タッチによる復帰操作は画面復帰だけに使う
- RTCをUTCとして読み、表示はJST固定
- CPU 240 MHz固定、無線なし、Grove 5 V出力なし
- 全画面RGB565スプライトによる遷移描画と、5秒ごとのフレーム時間集計ログ

ストップウォッチ、設定、外部アプリ起動は一覧の入口だけです。MultiFirmホストAPIと省電力PMは、試作の実測後に組み込みます。

## ビルド

```powershell
pio run
```

この段階の `partitions.csv` は単体試作用です。MultiFirm環境へ書き込む用途には使いません。

シリアルの `FrameStats` は、5秒間の描画数、33.3 msを超えた描画数、最長描画時間を示します。ドラッグ中に `missed_33ms=0` であることを最初の性能基準とします。

設計と試作の評価項目は [docs/design.md](docs/design.md) を参照してください。
