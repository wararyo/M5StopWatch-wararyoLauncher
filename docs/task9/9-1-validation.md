# 作業9-1: 共通型とモデル分割の検証

実施日: 2026-09-23。対象は[9-1の実装計画](plan-9-1.md)。
状態: ホストでの実装・検証完了。実機が必要な確認はユーザー指定により9-5へ引き継ぐ。

## 実装結果

- `TimeUs` を `core/Time.h` に移し、入力とは独立した共通型にした。
- 表示サイズ `Viewport`、描画領域 `DrawRegion`、倍率計算を分離した。List・Settings・External・Stopwatchの配置とヒットテストは全体フレームモデルを受け取らない。
- Settings・External・Stopwatchの `layoutModel()` を削除し、画面入力と描画レイヤーに同じ配置関数を使わせた。
- `WatchFace` は時計データと描画領域だけを受け取る。ホームのオフセットとクリップは画面構成側で計算する。各Layerは表示サイズ、当該機能モデル、表示可否だけを受け取る。統計表示の有効値のみSettingsLayerへ別途渡す。
- ScreenManagerが一覧操作の状態を保持し、機能別モデルをフレームごとに構成する。Renderer内の一覧とトースト関数も必要な値だけを受け取る。
- 輝度・消灯時間はフレームモデルから外した。Runtimeは `effectiveSettings()` を使い、輝度プレビュー・保存・取消・復帰の適用を継続する。設定メニューには保存済みの表示値だけを渡す。
- 統計表示の有効状態は非永続のRuntimeSettingsとしてアプリ側が保持する。ストップウォッチの計測状態と表示モデル・書式・40Hz周期を分離した。
- 既存の単一FramePlan、描画順、旧領域の消去、全面描画条件、起動確定画面の描画後に起動APIを呼ぶ順序は変更していない。
