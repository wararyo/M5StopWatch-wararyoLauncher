# 作業11: Analog・Noonish WatchFace

作成日: 2026-09-28。状態: 実装中（11-3まで完了）。上位計画は[全体計画](../plan.md)。
作業10のWatchFace契約、文字盤選択・永続化、背景復元を利用する。
見た目の基準は[Analog](../Images/WatchFace/Analog.png)と[情報あり](../Images/WatchFace/Analog-1.png)。
Noonishは[Noonish](../Images/WatchFace/Noonish.png)と[情報あり](../Images/WatchFace/Noonish-Info.png)を基準とする。

## 1. 到達点と合意済み仕様

設定からDigital／Forest／Analog／Noonishを選択でき、再起動後に選択と各文字盤の秒表示設定を独立して復元する。

- Analogは黒背景に白い時針・分針と中心円、外周のオレンジの丸で秒を表す。
- Noonishは時針・分針を反対側へ延長した2直線で背景を4領域に分け、針とともに色の境界が動く。白い針・中心円と、背景を明るくしたような秒の丸を表示する。
- 以下の更新間隔・操作・情報表示条件はAnalogとNoonishで共通とする。
- 秒の丸は12時位置を0秒として時計回りに1秒刻みで移動する。
- 時針は時の間の中間角度を使う。分針も秒に応じた中間角度を使い、10秒刻みの更新を許容する。
- ホーム静止中の長押しで秒の丸の表示／非表示を切り替える。タップは無操作。
- 上スワイプ・A/B・A+Bのシステム操作は既存仕様に従う。
- 右側の数字は当月の日付。針との重なりを許容する。
- 下部の情報欄はForestと同じ表示条件・情報選択を基本とし、針との重なりを許容する。

## 2. この計画で採用する実装上の初期値

以下は未指定部分を補う初期方針。実装時の目視確認で寸法・色を調整できるが、更新方式や保存仕様を変える場合は記録する。

### 2.1 角度と更新期限

時刻の秒を`s`、`q = floor(s / 10) * 10`とし、12時位置を0度、時計回りを正とする。

| 要素 | 角度 | 更新 |
|---|---|---|
| 秒の丸 | `6 * s`度 | 秒表示ありのとき、毎秒境界 |
| 分針 | `6 * (minute + q / 60.0)`度 | 毎分00／10／20／30／40／50秒 |
| 時針 | `30 * ((hour % 12) + (minute + q / 60.0) / 60.0)`度 | 分針と同じ10秒境界 |

秒表示なしでも針は10秒ごとに更新する。秒表示ありで毎秒描画するときも針の角度は同じ10秒単位に量子化し、丸だけが変わる秒に針を変更扱いにしない。
日付はローカル時刻の日を先頭ゼロなしで表示し、日付変更を反映する。

次回期限は`subsecondUs`を使って次の秒境界または10秒境界に合わせ、常に未来を返す。
バックグラウンド情報の期限は既存Runtimeによる合成を使う。情報更新が先に来ても針の更新粒度は変えない。
非表示・消灯中の文字盤更新は既存の可視性管理に従い、文字盤専用の周期タスクは追加しない。
復帰・時刻修正では最新スナップショットから位置を計算し、経過した回数を追いかけない。

### 2.2 見た目と情報欄

- 画像を基準とした相対座標で、viewportと円形安全領域に合わせる。目盛りは追加しない。
- 情報の有無で文字盤の中心・針の長さ・日付位置を動かさない。アプリ一覧への遷移でもForest同様に文字盤は静止する。
- 電池は正常値で`percent < 30 || charging`。取得失敗時の扱いも既存Forestの規則に揃える。
- バックグラウンド情報は登録順最大2件。電池は2件の枠に数えない。アイコン・ラベル・期限は供給元のデータを使う。
- 情報の横方向配置、幅制限、省略、不正アイコンの代替はForestの方式に揃える。
- 日付・情報欄はAnalogでは参考画像のグレー、Noonishでは参考画像の白〜淡い水色を基準とし、供給元の推奨色は使わない。Forestと揃えるのは情報の内容・条件・配置方式とする。
- 描画順は各文字盤の背景→日付・情報欄→時針→分針→中心円→秒の丸。針を手前に描き、重なりを避ける再配置は行わない。

### 2.3 初期状態・無効時刻・保存

- 初回の秒表示は既存文字盤と揃えて非表示。長押しで変更した状態を各文字盤の専用レコードへ保存する。
- 時刻無効時は時針・分針・秒の丸を隠し、日付を`--`にする。中心円と電池・バックグラウンド情報は表示する。
- 無効時刻では時計自身の更新期限を設けず、時刻の有効化や表示情報の変更で再描画する。
- 安定IDは`analog`、設定上の名称は`Analog`、専用キーは`wf_analog`。
- Noonishの安定IDは`noonish`、設定上の名称は`Noonish`、専用キーは`wf_noonish`。秒表示設定はAnalogと共有しない。
- 既存`VariantRecord`を利用する方針とし、未知版・不正値は秒非表示へ退避して自動上書きしない。
- 保存は長押しによる変更確定時のみ。保存失敗通知・再試行・RAM状態の維持は既存契約に従う。
- begin/endは描画資源のみを管理し、選択往復で秒表示設定をリセットしない。

### 2.4 Noonishの背景と秒の丸

- 時針・分針の方向ベクトルそれぞれに対して、画素が中心を通る有向直線のどちら側にあるかを判定し、2つの判定の組み合わせに4色を割り当てる。参考画像の時刻・配色を基準に左右と色の対応を固定する。
- 角度順に色を割り当て直さない。針が重なる／反対方向になる瞬間は一部の領域が消えることを許容し、追い越す前後も同じ判定規則を維持する。境界上の扱いとAAは部分描画でも同じ結果になるよう定義する。
- 背景の角度は針と同じ10秒単位に量子化する。丸だけが動く秒には背景の構図を変更しない。
- 4色の塗り分けを基本とし、一般的な半透明レイヤー合成基盤は追加しない。
- 秒の丸は固定の淡い水色ではなく、背後の背景色に白を一定比率で混ぜた色で描く。白の混合率は初期案50%とし、実機目視で「背景より少し明るい」見た目へ調整する。
- 丸が背景の境界をまたぐ場合は、画素ごとの背景色から明るい色を求める。丸全体を中心位置の1色で塗らず、境界の両側で透過したような見え方を保つ。AAの被覆率も反映する。
- 毎回復元した背景から色を計算し、前フレームの明るい丸へ重ねて徐々に白くなることを防ぐ。
- 時刻無効時の背景は、参考画像相当の10:07の角度に固定する初期案とする。針・秒の丸は隠し、日付は`--`として、現在時刻の表示とは区別する。
- 一覧背景色は既存の一覧文字が読める黒を初期値とし、Noonishは被覆されていない部分に背景を描く。

登録・設定一覧はともに容量4のため拡張不要。今回で4枠を使い切る。選択保存と設定UIは既存の候補列挙を使い、4件と「戻る」の操作・スクロールも確認する。
角度・更新期限・長押し・情報整形は両文字盤で共用し、背景・配色・背景復元方式は各文字盤が所有する。保存先とRAM状態は各インスタンスで独立させる。
フォント・アイコン・線描画は既存資産を利用する。電池や情報整形の共有が必要なら小さな描画非依存関数を抽出し、Forest固有の風景・座標には両文字盤を依存させない。
既存文字盤を含む大規模な共通化は今回の前提にしない。

## 4. 差分描画の方針

針・秒の丸・日付・各情報要素を別の変更要素として管理する。
位置や内容が変わった要素の旧・新境界矩形に、線幅・丸い端・AAの余白を含めてdamageを作る。
角度が変わっても境界矩形が同じ場合があるため、座標だけでなく角度／形状を変更判定に含める。

更新領域は各文字盤の背景から上記の描画順で復元する。変わっていない針や日付でも領域に重なるものは再描画する。
文字やアイコンが持つ不透明背景によって、手前の針が欠けないよう順序を守る。
クリップ対応の`drawWideLineClipped`等を使い、秒の丸・中心円もAAの端を含めdamage外を書き換えないことを確認する。
秒表示の切り替えでは旧位置の丸を確実に消去する。

毎秒の全面描画や全画面背景キャッシュを前提にしない。まず直接描画で成立させ、測定で必要と分かった場合に限って部分キャッシュやdamage算出の改善を検討する。現在のFramePlanとパネル転送は最終的に1つの境界矩形を使うため、複数領域の登録だけで転送量が減るとは仮定しない。
斜めの長い針では境界矩形が広くなるため、10秒境界の更新負荷を丸だけの更新と分けて測る。

Noonishは背景の角度が変わる10秒境界に、針の矩形だけでなく背景の変更範囲もdamageへ含める。
初期実装では可視文字盤領域全体の復元を許容し、実機負荷が問題になる場合に旧・新境界間の領域へ絞る。背景の構図が変わらない秒は丸の旧・新領域だけを更新する（他要素の変更分は別途合成）。
多色背景上の文字・アイコン・針のAAは復元済み背景へ合成し、黒や単色の矩形を残さない。既存の不透明背景つき描画を無条件に流用しない。
背景境界が静止中の秒の丸を横切る更新でも、丸の明るい色を新背景に合わせて描き直す。

## 6. 検証と完了条件

### ホスト検証

- 0／3／6／9時の向き、中間角度、09→10秒・59→00秒・11:59→12:00・23:59→翌日の変化。
- 秒表示なしの次回10秒境界、表示ありの秒境界、秒未満の補正、境界直前・ちょうど、無効時刻。
- 同じ10秒区間では針の角度・変更判定が一定であること。情報更新で更新粒度が変わらないこと。
- 長押しでのみ秒表示を切り替え、タップは無操作。レコード分離、再起動復元、未知版・破損・保存失敗。
- 電池29／30／31%、充電・取得失敗、情報0／1／2件、長いラベルと不正アイコン。
- 4文字盤の選択・往復、Analog／Noonishの秒表示設定の独立性、既存設定保持。未知IDテストに`analog`や`noonish`を使う箇所は、実際に未登録を検証するケースか確認して調整する。
- Noonishの4色の対応、境界上の判定、針の一致・反対向き・追い越し・角度の一周、時刻無効時の固定背景。
- 秒の丸の背景別の明色化、境界をまたぐ丸の画素ごとの色、同一入力の再描画で色が変わらないこと。

### 描画・実機検証

- 部分描画と全面描画の画素一致。秒の丸の全60位置と、針が重なる位置・水平／垂直／斜めを含める。
- 秒の丸の非表示化、日付変更、情報増減、電池条件変化。日付・情報と針が交差した後に残像や欠けがないこと。
- 一覧による部分被覆と往復、通知・統計表示の出現／消去、消灯復帰と時刻修正。
- 両文字盤で参考画像に対する針の太さ・長さ・丸の径と軌道・日付と情報欄の視認性を目視確認。
- Noonishは背景境界と文字・アイコン・秒の丸が交差するケース、10秒境界と秒更新の同時発生、針の一致前後で画素一致を確認。境界のギザつき・残像・不透明な文字背景が出ないこと。
- 秒表示あり／なし、情報あり／なしで、通常更新・10秒境界・一覧遷移の描画時間と転送量を分けて記録。
- Noonishの10秒ごとの背景更新をAnalogと区別して測り、操作応答と消灯復帰への影響を確認する。
- 反復選択時のメモリ、内部RAM／PSRAMの余裕、ビルドサイズと4MiB上限、初期化失敗時の既存退避経路を確認。
- 通常版・描画検証版・測定版をビルドし、既存ホストテストとDigital／Forestの主要描画・選択ケースを回帰確認。
