# 10-3: Digitalのフォントと情報欄

作成日: 2026-09-25。状態: 実装計画。依存は[10-1](plan-10-1.md)・[10-2](plan-10-2.md)。
表示仕様は[上位計画](plan.md)と[Digital](../Images/WatchFace/Digital.png)・[情報あり](../Images/WatchFace/Digital-Info.png)を基準にする。

## 1. 到達点

滑らかな時刻・日付・電池・情報ラベルを描き、時分／時分秒、情報0／1／2件に対応する。
電池は常時表示。実行情報はアプリが整形した文字列を使い、文字盤では書式を変更しない。
この段階の背景は黒。Forest用の多色背景復元は10-4以降へ分ける。

## 2. 資産の生成とロード

現行`tools/build_font.py`はGenShinGothic28の出力先と文字集合が固定されている。
`--output`・`--chars-file`を追加し、従来の引数省略時の動作を維持する。
新しい時刻用フォントに日本語全体を重複収録しない。

- 時刻: 数字、コロン、ハイフン。時分用の大サイズと時分秒用の小サイズを別資産にする。
- 補助表示: 英語日付・APPS・電池・ASCIIラベル用のサイズを用意する。
- 非ASCIIラベル: 既存の日本語サブセットと代替グリフを使う。任意Unicode全収録は保証しない。
- 選定する書体・サイズは実装前の10-0で画像と比較する。未選定のフォント名やライセンスを確定扱いにしない。

`ui/graphics/WatchFonts.*`を追加し、時刻大／時刻小／補助のアクセサーを提供する。
既存VlwFontと同様にPointerWrapperとVLWfontの寿命を保持し、setFont後の切替でロード済みオブジェクトを失わない。
`src/CMakeLists.txt`へ埋め込み資産を追加する。生成元・ハッシュ・生成コマンド・ライセンスを`docs/task10/fonts.md`へ記録する。
フォントロード失敗時は既存組み込みフォントで時刻を表示し、失敗を一度診断する。

## 3. 配置・情報表示

`DigitalLayout.h`にViewport・バリアント・情報件数と文字計測値から表示矩形を返す純粋計算を置く。
参考画像の466角を固定せず、実表示サイズを使う。AAの縁と文字の張り出しを矩形へ含める。

- 情報0件: 時刻とAPPSを通常配置。
- 情報1件: 1つのピルを中央に配置。
- 情報2件: 同じ安全領域内に2つを配置。登録順を左から右へ維持。
- ピルはアイコン＋ラベル。既知のストップウォッチIDに対応するアイコンを使い、未知IDは汎用表示へ退避。
- 長いラベルは元のスナップショットを変更せず、`fitText`相当で省略する。数値を再解釈しない。
- 日付は従来の英語・24時間を維持。無効時刻はバリアントに応じたハイフン表示とSET TIME。
- 情報欄が増減したフレームで旧領域も消し、APPSタップ矩形を同じ配置へ更新する。

電池アイコン・ストップウォッチアイコンはグレースケールマスクか既存の滑らかな図形で描く。
情報アイコンの対応は機能側の小さな表へ置き、共通uiへLaunchRegistry依存を追加しない。

## 4. キャッシュと差分描画

現在は時刻文字列だけでキャッシュを判定し、`00:00`のサイズで確保している。
時分秒・フォント・色・バリアント・幅をキャッシュキーへ追加し、表示変更で旧キャッシュを再利用しない。
最大必要サイズを初期化で確保する案をまず測定し、内部RAMを圧迫する場合はバリアント変更時に再確保する。
毎フレームの確保・失敗後の毎フレーム再試行は禁止。失敗時は直接描画する。

Digitalは黒背景付きRGB565部分キャッシュを使える。これをそのままForestへ共有しない。
ピル内部の文字はピル背景色と合成し、AAの縁へ黒を混ぜない。
情報件数・ラベル・日付・電池・時刻・レイアウト変更を各Elementの矩形／fingerprintへ反映する。
同じ秒内の別のdirty理由でもキャッシュ生成を繰り返さない。

## 5. 実装順序

1. 生成ツールの複数資産対応を追加し、既存日本語資産の再現性を確認する。
2. フォント・マスクの埋め込みとロード失敗時の退避を実装する。
3. 時分／時分秒の配置とキャッシュを更新する。
4. 0／1／2件の情報欄、未知ID、省略、APPS矩形を実装する。
5. 描画診断へ画像ケースとキャッシュ失敗ケースを追加する。

## 6. 検証と完了条件

- ホスト: 配置の安全領域、0／1／2件、文字幅変更、APPSヒットテスト、元ラベル不変。
- 実機ピクセル比較: 分・秒・日付境界、電池0／30／100／不明、充電切替、情報追加・削除、長い文字列、トースト、遷移途中。
- キャッシュあり／なしで同じフォントによる画素一致。フォント自体の退避時は一致でなく、読める表示の継続を確認する。
- 目視: 数字の形・太さ・AA、日付との間隔、ピルの端、秒表示の可読性と円形端。
- 性能: 時分静止・秒更新・情報秒更新・一覧遷移の描画時間、転送領域、キャッシュ量・最大連続RAM。
- 4MiBホスト上限を検査する。通常／測定／描画検証の各構成をビルドする。

描画一致だけで参考画像への適合を判断せず、見た目と実機性能を別項目として`10-3-validation.md`に記録する。
全体計画への補足候補: フォント生成ツールの固定出力を解消すること、非ASCIIラベルのフォント退避、100時間以上の幅。
