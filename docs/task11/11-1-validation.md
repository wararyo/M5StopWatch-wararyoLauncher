## 1. 実装の要点

| 場所 | 内容 |

計画からの補足・決定:

- 制御は計画案の`AnalogControl.h`へ分けず、Digital／Forestと同じく`AnalogLayout.h`に置いた（計画2節で許容）。
- 針の角度は整数`step = (hour%12)*360 + minute*6 + second/10`（0〜4319）から導く。分針は`step%360`度、時針は`step/12`度で、計画の式と等しい。変更キーはこの`step`・`step%360`・秒の整数で、浮動小数点を比較しない。0時と12時は同じキーになる。
- 無効時刻は`valid=false`とし、キーを0（表示中は1以上）にして0時と区別する。時0〜23・分0〜59・秒0〜60・日1〜31の範囲外も無効とする（Digitalの検査に揃えた）。
- **うるう秒**: 既存文字盤は`tm_sec<=60`を有効とし、`TimeDigits`で59として表示する。Analogも60を59として扱う。10秒期限では`:60`の次の境界は`:59`と同じ次の`:00`になる（`nextTenSeconds`）。
- `strokeBounds`は`drawWideLineClipped`の走査範囲と同じく半径+1pxを外側へ丸める。描画される画素（距離<r+0.47）はfloor／ceilだけでも収まるため、余白1pxは保守側。
- 情報欄は「針との重なりを許容」「情報の有無で動かない」ため、レイアウト関数は情報や秒表示を入力に取らない。viewportと日付の基準x座標だけで決まる。
- `infoGroupLimits`は元の実装で未定義だった4件以上の入力を`InfoRowMaxGroups`（3）へ切り詰めた。3件以下の結果は同一。

## 2. 参照画像から取った配置

座標は描画関数と同じ「画素中心が整数」の系。466px画像の中心は(232.5, 232.5)で、両参照画像の針と中心円はこの点に対して左右対称だった。
長さは中心から丸い端の中心までで、viewport短辺/466でスケールする。円の中心は`((w-1)/2, (h-1)/2)`。

| 要素 | 値（466px） | 根拠 |
|---|---|---|
| 時針 | 長さ122、幅10 | Analog.png の6時方向。x=228〜237が不透明、端の丸みから端の中心y=354.5 |
| 分針 | 長さ169、幅5 | 12時方向。x=231〜234が不透明・両端128（半被覆）、端の中心y=63.5 |
| 中心円 | 半径12 | x,y=221〜244 |
| 秒の丸 | 軌道199.5、半径11.5 | x=222〜244、y=22〜44。参照の丸は軸より0.5px右にあるが、回転のため中心軸上に置いた |
| 日付 | 墨の中心 Analog x=361.5、Noonish x=369、y=中心 | "20"の墨がAnalog x=340〜383、Noonish x=348〜390、ともにy=220〜245（高さ26px） |
| 情報欄 | 中心y=357。アイコン28、電池18×30、間隔12／28 | Analog-1.png・Noonish-Info.png の各グループ位置がForest-Info.pngと完全一致し、行だけ10px上（Forestは367） |

- Noonish.png の針も同じ長さ・太さ（時針の到達126、分針171を画素から確認）。
- 日付フォントは未選定。レイアウトは描画側が測った幅と墨の上下を受け取る（`placeAnalogDate`）。参照の"20"は幅44px・墨26px。
- 色（11-2／11-3への引き継ぎ、未実装）: Analogの秒の丸(234,81,16)、日付・情報(102,102,102)。
  Noonishの4領域は上(96,196,218)、右(144,214,229)、下(131,167,209)、左(78,130,189)、日付・情報(222,243,247)。
- Noonishの参照画像の針は時針約298°、分針約44〜45°で、10:07（303.5°／42°）とは一致しない。無効時刻の固定背景は計画どおり10:07（`step=3642`）とする前提。
- **白の混合率**: Noonishの秒の丸は上領域の上で(207,237,244)。背景(96,196,218)と白の混合率はRGBいずれも約70%で、計画の初期案50%より高い。11-3の初期値として70%を検討する。
