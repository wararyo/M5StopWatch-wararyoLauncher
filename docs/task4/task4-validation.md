PlatformIO espressif32 6.12.0 / ESP-IDF 5.5.0 / M5Unified 0.2.16 / M5GFX 0.2.28。

| 環境 | サイズ | 検査 |

| m5stopwatch-render-check | 1,018,151 bytes | 成功 |

すべて4MiB以内（24.1〜24.3%）。作業3完了時点の955,776 bytesからの増加は約53KiBで、
内訳はフォント部分集合の +13.7KiB（307→326グリフ）と設定画面・ストア・時刻基盤のコードです。
SDK設定、固定MultiFirm版、正規パーティション、hostイメージ検査、install-hostの
ローカルプレビュー、診断文字列の環境分離がすべて成功しました。
このPC検査では実機への接続・書き込みは行っていません。

`REQUIRES` に `nvs_flash` を追加したため、最初のビルドで
`Couldn't find target config target-...json` が出ます。`.pio/build/<環境>` を削除して再実行すれば直ります。

M5UnifiedのRTC関連警告（`RTC_PowerHub_Class.cpp` の配列境界）はRTC APIを参照したことで
新たにコンパイル対象へ入った依存側の既知警告で、依存の変更はしていません。
