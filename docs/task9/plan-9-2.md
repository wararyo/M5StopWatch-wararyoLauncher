## 目的と範囲

アプリ一覧を共通ListView・ListControllerへ移し、設定が使える契約を確立する。
アプリ一覧の見た目・操作・起動先は変えない。設定への適用は9-3、ホーム操作全体とRendererの構成分離は9-4。
抽出と新しいキャッシュを別の変更として検証する。

## 1. 部品と所有権

| 配置・部品 | 責務と所有するもの |
|---|---|
| `ui/list/ListModel.h` | RowId、行データ、件数付きの読み取り用データ、ListStateの表示スナップショット |
| `ui/list/ListLayout.*` | Viewport・スクロール・オフセット・クリップから行矩形を計算。描画とヒットテストで共有 |
| `ui/list/ListController.*` | 選択・ドラッグ・慣性・停止・期限を所有。決定した行IDを結果として返す |
| `ui/list/ListView.*` | 計画済み行、Element履歴、文字整形結果、表示行の画像キャッシュを所有 |
| `features/launcher/AppListLayer.*` | AppRegistry・SlotCatalogから表示行を組み立て、ListViewへ渡す薄い機能レイヤー |
| `ui/overlays/ToastLayer.*` | トースト矩形、文字整形、Element履歴、plan/paint |

共通リストはAppRegistry、ScreenId、SlotStatus、SettingsViewを参照しない。
行は安定ID、ラベル、任意のアイコン参照、見た目（色・薄い表示）、決定可否を受け取る。
アイコンの汎用ビュー型は `ui/graphics/` に置き、IconIdから埋め込み画像への解決はランチャー側で行う。
Gfxの型定義も共通描画ヘッダーへ移し、リストやトーストがWatchFaceへ依存しないようにする。

行の構築は一時配列へのポインタを返さない。機能側の永続領域かフレーム所有領域に置き、paint終了まで不変にする。
文字キャッシュのキーはポインタ値ではなく内容を比較・保持する。配列内の文字参照を持つモデルのコピーで、
コピー元へ参照が残らない設計にする。RowIdは各リスト内で一意とする。

## 2. 配置と容量

- 行数は入力で渡す。現行の5件・最大添字4を共通実装から除く。
- 遷移率は共通リストへ渡さず、画面側が算出したYオフセット・クリップを渡す。
- 円弧・行間84px相当・選択時の拡大・省略幅を維持する。アイコンなしではアイコン領域の左端から文字を置く。
- データ件数と表示用スロット数を分ける。固定容量は表示領域と行高から必要な可視行数を算出して決め、上限を文書化する。
- 表示スロットを別の行へ再利用するときも旧矩形をFramePlanへ渡す。非表示・件数減少時は旧要素を空矩形で登録する。
- 0件では選択なし・決定なし、1件ではスクロールなし。行削除時は残存IDを優先し、消えた選択は有効範囲へ補正する。
- 表示スロット不足では行を黙って落とさず、全面描画＋キャッシュなしの全可視行描画へ退避する。
  FramePlan容量超過の退避とは区別し、入力の行数は制限しない。

## 3. 操作の抽出

ScreenManagerの一覧用ドラッグ・慣性処理をListControllerへ移す。
180ms補間、90ms先読み・最大1.5行の着地予測、単調なHermite補間、16msの次フレームを維持する。
ホーム↔一覧の補間はこの段ではScreenManagerに残す。

| イベント | 共通部品の動作 |
|---|---|
| A | 次の行へ循環、選択行を可視位置へ移す。アニメーション中は現在位置から再目標設定 |
| B / タップ | 選択/ヒットした行のIDを返す。実際の起動は画面側 |
| ドラッグ | 縦方向のみ扱い、解放後のタップを決定にしない |
| 慣性中のTouchStart | 慣性を止め、その押下群の解放を決定にしない |
| Cancel / 退場 | ドラッグを解除し、呼び出し側の方針に応じて整列または期限解除 |

一覧先頭での下ドラッグは画面側が開始時に取得し、解放まで同じ所有者が処理する。
一覧スクロールとホーム遷移へ同じジェスチャーを二重配送しない。共通部品はホームへの遷移を実行しない。
薄い外部行も決定でき、理由画面へ進める現行仕様を維持する。
決定不可の行は選択可能・決定結果なしとする。新たな業務動作は加えない。

## 4. 描画と最適化

まず既存の直接描画をListViewへ移す。その後、省略結果の保持を追加する。
更新キーはRowId、元文字列、フォント、倍率、利用可能幅。位置だけの変化では再整形しない。

文字画像キャッシュは独立した変更で追加する。表示行だけを対象とし、画素形式・最大bytes・割当先を記録する。
現在の文字色・背景色とピクセル一致する方式を使い、色を焼き込む場合は色を更新キーへ含める。
空文字、長い日本語、未収録グリフも直接描画と同じ表示にする。
通常フレームで同一内容の再確保をせず、失敗時は直接描画に退避する。失敗した同じキーを毎フレーム再確保しない。
無効化・解放・再入場の扱いを明示し、無制限にキャッシュを増やさない。
アイコン合成画像の新規キャッシュはこの段の必須としない。描画経路を共有し、追加は9-5の内訳測定で判断する。

ToastLayerへは矩形・文字・Element・ハンドルをまとめて移す。
通知の寿命はScreenManagerに残す。表示/消去による全面再描画と、画面より前面・統計より背面の順序を維持する。
全plan→resolve→全消去→全paint→転送は一回のFramePlanで行う。
