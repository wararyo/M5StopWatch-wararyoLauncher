## 1. 到達点

両文字盤で共用する角度・配置・更新期限・長押し・情報条件をGfx非依存で実装する。
同じ入力から同じ結果を得られ、2つのインスタンスが独立した秒表示設定を保持・保存できることをPC上で確認する。

Forestの電池条件等を共有するなら独立した小さなヘッダーへ抽出し、風景配置には依存させない。Forestの既存テストで挙動を固定する。

## 3. 角度と配置

秒を`s`、`q=(s/10)*10`（整数演算）とする。

- 秒: `6*s`度。
- 分: `6*(minute+q/60.0)`度。
- 時: `30*((hour%12)+(minute+q/60.0)/60.0)`度。
- 12時を0度とし、端点は`x=cx+length*sin(angle)`、`y=cy-length*cos(angle)`。

変更判定には12時間内／1時間内の10秒番号や秒番号など整数キーを使い、浮動小数点のメモリ表現を直接ハッシュしない。
有効性を持たせ、無効時刻を0時として扱わない。入力範囲を検証し、うるう秒の丸め／無効化は既存文字盤との整合を調べて記録する。
参考画像から中心、針の長さ・太さ、中心円・秒円の径、秒円の軌道、日付と情報欄の位置を名前つき定数へ落とす。
viewportの短辺に対してスケールし、円の中心はviewport中心とする。秒・情報の有無で針を移動しない。
端点の最小最大値に線半径とAA余白を足し、floor／ceilで外側へ丸めた矩形を返す。
情報欄はフォントの測定結果を入力とし、円形安全領域内に電池＋最大2件を配置する。文字の測定・省略は描画側に置く。

## 4. 操作・期限・保存

秒表示ありは既存の`nextSecond`相当、非表示は
`now + (10 - s%10)*1000000 - subsecondUs`を返す。境界ちょうどでも次の境界を返す。
無効時刻・範囲外の秒未満では`INT64_MAX`とする。復帰・時刻修正は最新入力から計算し、経過した回数を追いかけない。
情報期限は`backgroundInterest()`を通じて既存Runtimeへ渡し、時計期限へ二重実装しない。

制御インスタンスは各文字盤が所有する。

- `bindPreferences`: 自分のポートへVariantRecordを束縛し、初回は秒非表示。
- `handle`: LongPressだけで切替・保存し、changedと保存失敗を返す。Tapは無操作。
- `update`: Forestと同じ電池条件、最大2件の情報数を更新。同じ入力で状態が進まない。
- `nextUpdate`: 副作用なしで期限を返す。
- `backgroundInterest`: 表示する先頭2件だけを返す。

既存version 1＋バリアント値を使い、`wf_analog`と`wf_noonish`へ分離する。
欠損・破損・未知版は読み込むだけでは上書きしない。保存失敗・再試行・非束縛時のRAM動作はVariantRecordの既存契約を保つ。

## 5. 実装順序

1. 配置定数とモデルの入出力を定義する。
2. 角度・境界矩形・整数の変更キーを実装する。
3. 10秒期限、長押し、保存、電池・情報を接続する。
4. 境界テストを追加し、既存ホストテストとともに実行する。

## 6. 検証と完了条件

- 0／3／6／9時、10:07、12時間違い、09→10秒・59→00秒・日付越え。既知の方向・端点を確認。
- 同じ10秒内では時分の端点・キーが一定。10秒境界で分針が1度進む。
- 12:34:09.750で秒OFFなら250,000µs後、12:34:10.000なら10,000,000µs後の期限。
- 秒ON、無効時刻、境界前後、時刻の前進／後退。
- 秒と情報の有無で中心が不変。AAを含む端点と円が矩形へ収まる。
- 電池29／30／31%、充電の既知／不明、残量不明の初回／表示中。
- 別キーの2インスタンス間で長押し・再読込が干渉しない。破損・未知版・書込失敗・再試行。
- 通常更新と期限問い合わせで保存が起きない。

`python tools/test_runtime.py`のログはファイルへ直接保存し、終了コードと要約だけ取得する。
